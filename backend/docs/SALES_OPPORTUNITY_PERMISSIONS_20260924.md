# 第 5 项：销售创建商机与可配置权限

用户随后确认的可配置 RBAC 取代此前“只修改后端并按主角色判断”的实施范围。当前规则、迁移、验证与发布边界统一见 [可配置权限交接](../../docs/RBAC_20260924.md)。

- 多角色按功能及其各自范围取并集，账号禁用优先。
- 产品销售、产品销售主管按有效销售任职具备默认创建权限；纯 FDE 和运营默认不开放，可明确追加授权。
- 功能权限不改变业务岗位、部门与业绩归属。
- 独立角色模板和单账号增减支持后台配置，前后端、数据库均实施校验。
- 基准 `45ea572`，工作分支 `codex/configurable-rbac`；尚未部署或更新微信体验版。

## 修复边界

- V150 将后台审计、系统日志、飞书读取的请求级权限判断改为 SQL initplan，每条语句只计算一次；租户行过滤仍逐行执行。
- 飞书 Worker 分支仍先判断并拒绝管理权限路径，独立 Worker 策略与 ACL 不变。
- 业务操作投影采用相同的语句级检查，新增匹配历史快照关联的表达式索引。
- 缓存仅限一条 SQL 语句；换账号、换公司、下一事务的撤权仍重新计算。
- 页面导航开始加载即更新标题，失败后也不会残留上一个页面的标题。
- 不延长 30 秒查询超时、不隐藏错误、不修改业务数据，不调整冻结的 Agent 模型、提示词或思考档位。

# 直连模型接口后台配置

2026-09-16。范围：后端、运营管理网页、V099 配置表。小程序接口与源码不变。

## 管理入口与用途

管理员登录后进入「模型接口配置」，也可由「AI 调用管理 → 接口配置」进入。左上角公司决定配置作用范围。

- 文字模型与业务兜底：通用文字模型，以及业务运行策略使用原接口时的调用。业务中台仍按原策略优先。
- 语音转文字：语音输入、录音转写、拜访音频导入，单独的模型、地址和密钥。
- 语音合成：预留用途，可配置和测试；当前没有启用的业务调用入口。

支持完整 HTTPS 请求地址、模型、密钥、服务商显示名、单次超时和重试次数。文字/转写使用当前兼容协议，语音合成使用原有协议。不同协议需要适配，不支持随意编辑请求体、认证头或可执行脚本。

## 操作流程

1. 编辑所选用途。初始继承当前默认接口，未发布时不改变现有调用。
2. 选择「独立接口」，输入完整 URL、模型和密钥，点击「测试接口」。固定样本最长等待 45 秒，只尝试一次，不读取客户事实。测试可能收费。
3. 通过后 15 分钟内点击「发布配置」。只有同账号、同公司、同用途、同版本的成功回执可发布。测试失败、过期、其他管理员已更新时，当前配置不变。
4. 后续 API/Worker 调用读取发布版本，无须重启服务。正在进行的请求继续使用开始时选定的配置。
5. 历史版本只载入非秘密字段，仍需重新测试和发布。不会复活旧密钥。

「继承现有默认接口」与「停用直连接口」只进行本地配置检查，不声称模型联网测试成功。停用文字直连不关闭中台；若中台失败，原接口兜底也将不可用。发布独立接口后，每次真实调用的元数据记录公司、用途、服务商和配置版本。

密钥留空保持当前密钥。同公司但换域名/端口必须重新输入目标服务商密钥；历史版本不提供旧密钥。密钥使用现有独立 AES-GCM 密钥环加密，API 不返回密文、明文或历史密钥，仅显示尾号。密钥环缺失时阻止保存，不能退回明文存储。

公网 HTTPS 地址校验、DNS 解析校验及连接 IP 固定共同阻断内网/元数据访问；不跟随重定向、代理环境。未配置新用途时，原来的接口配置兼容保留。

## 数据与接口

V099 仅新增配置数据结构和权限，不修改客户、商机、拜访、账号或中台绑定：

- `config.model_api_test`：加密候选配置、测试回执、15 分钟有效期，UUID 测试标识防重复调用；每公司/用途每分钟最多 5 个新测试。
- `config.model_api_release`：追加发布版本，禁止修改/删除。密钥与配置在同一版本内。
- `config.model_api_current`：当前公司/用途的发布指针。

应用普通运行角色受行权限限制；只有当前有效的系统管理员可写。后续新建运行角色由迁移器的权限对账函数补齐表权限。网络测试期间不持有数据库连接。

实际 OpenAPI 由应用导出。接口均要求密码登录、系统管理员身份、当前公司授权：

- `GET /api/v1/admin/model-apis`
- `GET /api/v1/admin/model-apis/{purpose}/releases`
- `POST /api/v1/admin/model-apis/{purpose}/tests`
- `GET /api/v1/admin/model-apis/{purpose}/tests/{test_id}`
- `POST /api/v1/admin/model-apis/{purpose}/publish`

测试请求含 `request_id`、`expected_version`、`configuration`、可选 `api_key`；发布请求仅含 `test_id` 和 `expected_version`，不能替换测试过的参数。

## 验证

- 后端单元/契约测试（含凭据、用途绑定、DNS 固定、外部错误脱敏、发布条件）。
- `backend/tests/system/verify_model_api_postgres.py`：临时 PostgreSQL、非超级用户，校验租户隔离、密钥加密、并发发布、测试幂等、版本只读、默认继承、用途停用和后建角色授权。
- 完整 PostgreSQL 集成脚本包含本专项。
- 隔离网页实际验收：管理员登录、编辑、检查、发布、版本载入和非法地址拦截。

连接测试只证明当前固定样本与协议可用；不能替代不同能力的业务语义验收。生产固定样本与部署回执见同目录 evidence，缺少证据不得宣称真实可用。

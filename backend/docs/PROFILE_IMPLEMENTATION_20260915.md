## 已实现

- 运营后台扩展现有目标管理、目标修改审批。部门、团队、个人分别设置；销售与 FDE 部门目标分开，历史年度目标保留，未自动折算为季度。
- 小程序复用季度目标底部表单：回款、确收、商定依据／调整原因、原值及待审批值。本人首次提交直接生效；已有值变更整单审批，通过前仍按原目标计算。主管、经理选择别人时只读。运营预设后本人再改也需要审批。
- 多指标目标采用原子审批、版本校验、幂等回放及完整审计。运营调整已生效目标时关闭冲突的整张待审申请。金额提交和回填使用十进制精度，历史季度不显示本人编辑入口。
- 当季度目标与当季度已登记实绩对应，按实绩发生日归季。客户效率为第一、二象限／全部客户；商机效率为 A、B 级／总商机。团队先去重再计算占比，未评估计入分母并显示覆盖情况；全无评估不补造评分。
- 三个标签共用具体人员／团队选择，目录使用稳定 ID 和实际有效组织关系。选人不改变登录身份；身份变化、请求失败或旧响应迟到时清空旧主体数据。FDE 保留项目、协作及专属画像，与销售共用控件风格。
- 客户地图、客户列表与个人效率共用已确认归属投影和主体评估选择。V092 仅提供既有授权客户的确认归属 ID，不放宽认领申请、客户或评分表权限。

接口新增 `GET /profile/scope-options`、`GET /fde/scope-options`、`POST /targets/batch` 及后台整单审批接口；真实 OpenAPI 已重新导出。V091 为目标整单状态机，V092 为归属投影；详见[数据库交接](../../database/TARGET_BATCHES_V091.md)。

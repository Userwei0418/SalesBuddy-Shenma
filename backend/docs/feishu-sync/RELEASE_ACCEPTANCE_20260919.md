小程序继续访问 `https://www.ericepc.com/api/v1`。源码 `frontend/miniprogram/utils/apiClient.js` 的原有入口保持：

- 客户新建：`POST /customers`。
- 商机创建/修改：`POST /customers/{customer_id}/opportunities`。
- 正式跟进确认：`POST /visits`；仅保存草稿或完成结构化识别不等于正式写入。

通知发生在服务器端：业务提交成功 → 同事务产生同步事件 → 专用 Worker 更新目标多维表格 → 对符合条件的首次新增发送群卡片。小程序不直接调用飞书，也不携带飞书凭证。通知仍受公司、对象范围、正式新增标识及同步/通知开关约束，调用同一个接口并不意味着所有请求都发通知。

新增页面为运营后台 `/admin#feishuSync`，静态资源随后端部署；它不是小程序页面。后续若仅调整应用、Base、字段映射、统一群或部门路由，按公司后台配置保存、校验、启用即可，不需重发小程序。

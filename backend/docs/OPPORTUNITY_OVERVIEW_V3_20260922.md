# 商机总览 v3 统计口径

接口：`GET /api/v1/opportunities/overview`。响应字段保持兼容，`definition_version` 改为 `opportunity_overview_v3`。

| 指标 | 口径 |
|---|---|
| `total` | 当前授权范围内未删除的全部商机，包含 open、won、lost。选择季度不改变这个存量分母，也不按预计关单日期裁剪。 |
| `newCount` | 真实业务建单日落在所选期间的商机，包含各状态。历史来源缺失或非法日期时不计入新增。 |
| `active` | 在所选期间有正式跟进的去重商机，沿用不含 lost 的规则；多商机关联按每个关联商机去重。 |
| `won` | 实际成单时间落在所选期间的 won 商机。缺少实际成单时间时不以预计关单日代替；全部时间仍可统计其 won 状态。 |
| `missingCreatedDates` | 当前授权存量中无法确定业务建单日的商机数；不把导入时间当作原建单日。 |
| `missingWonDates` | 选择期间后缺少实际成单时间的 won 商机数。 |
| `missingCloseDates` | 保留兼容字段，仅说明预计关单日期缺失，不会影响全部商机存量。 |

`quarters=[]` 明确表示跨年份全部时间。选择某年全年应发送该年份及 `quarters=[1,2,3,4]`。日期按上海业务日解释。

历史日期只读投影：`import_type=crm_history` 时优先读取 `import_meta.source_fields[商机创建时间]`；新来源为空时读取旧导入的 `import_meta.raw_fields[商机创建时间]`。已提供但非法的新来源不会降级到另一条旧日期；全部缺失时保持未知。兼容 ISO 日期、带时区或无时区的 ISO 时间，以及 `YYYY/MM/DD`。普通新录入使用 `created_at`。日期格式异常和时区越界不会导致统计请求失败。

商机列表年份目录复用同一规则，同时保留预计关单年、实际成单年。仅传输授权商机的必要日期投影，不读取整份导入正文，不增加权限，不从分页样本计算总数。

本次不修改 `crm.opportunity.created_at`、导入原值或飞书 `source_created_at`。它们继续表达系统入库审计事实；V4 的“系统创建时间”含义不变。无数据库迁移。

验证覆盖：包含输单的存量分母、不同年份及季度、原日期与导入日期分离、普通新录入、来源缺失或非法、上海日期边界、年份目录、跨销售和跨租户隔离、读取不改审计时间。测试使用合成数据及隔离 PostgreSQL。

# 工作邮箱账号维护

后台开通与编辑成员支持完整工作邮箱作为登录账号。编辑时在原用户UUID上修改 account_code，保留密码和业务关联，撤销该用户旧会话。旧登录名不作为别名保留；认证继续大小写不敏感。旧客户端省略 account_code 时保留原登录名。平台管理授权身份继续禁止从普通成员表单修改。

接口：POST /api/v1/console/accounts 扩展账号格式；PUT /api/v1/console/accounts/{user_id} 新增可选 account_code，沿用管理权限、乐观版本、幂等与审计链路。无数据库迁移。本次不接手机号、验证码、邮箱SSO或自助注册。

验证：邮箱契约与非法输入测试；真实PostgreSQL验证改名后的UUID、密码、角色和部门不变，旧登录名失效，大小写重复账号被拒绝。生产名单仅保存在受限运维材料，不进入源码。

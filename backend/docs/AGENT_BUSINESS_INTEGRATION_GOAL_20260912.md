## 每个 Agent 的完成标准

1. 实际业务项目已包含接入实现，原 API 保留，单 Agent 配置可开启、关闭和回退；前端显示开关与后端提供方开关独立。

3. 正常场景结果符合业务事实和既有输出格式，业务运行与中台会话/任务标识能够对应。
4. 关闭中台路由时，真实原 API 能独立完成业务任务。这是原路径与开关验证，不能冒充失败兜底。
5. 在限定测试用户和有效期内，受控拦截一次中台尝试，令同一业务运行自动进入原 API，且原 API 真实返回并只保存一份最终回答。受控故障必须在日志中明确标注，不能伪造真实中台 HTTP 失败记录。

7. 记录源码版本、Agent 绑定、启用范围、业务运行 ID、调用路径、校验结果及未验证项，并同步关联任务。

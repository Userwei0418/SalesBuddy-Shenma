# 首次改密提示改为 8–128 位

> 发布更新：本批代码已部署，数据库 V125；小程序 1.0.8 已上传，用户确认设为体验版。以下设计/本地验证阶段的待部署措辞保留为过程记录，最终状态见 [1.0.8 发行回执](../../docs/RELEASE_1.0.8_20260923.md)。

按用户确认，将登录页新密码提示从“请输入12–128位新密码”调整为“请输入8–128位新密码”。最大输入长度仍为 128，实际校验由后端统一执行；不新增字符组合要求。

后端同批变更已覆盖开通账号、首次改密、主动改密和重置密码，详见 backend/docs/PASSWORD_POLICY_20260923.md。应先部署接受 8 位密码的后端，再上传新小程序包。当前体验版仍为 1.0.7，本改动尚未上传。

前端 773 项测试通过；页面注册、JSON 和 JavaScript 语法检查通过。

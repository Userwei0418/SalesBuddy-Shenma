# 1.0.5 至1.0.6 简要变更

## 1.0.5 相比之前（9月18日晚至19日凌晨）

- 登录：记住密码、多账号切换回填、已保存账号前缀推荐。
- 任务：提交完成说明→发起人确认或驳回→重提；自建自领直接完成，补齐相关通知。
- 任务展示：完成与历史说明字体、排版统一。
- 地图：象限筛选放大、列表和数量联动；重叠客户点弹出名单选择。

## 1.0.5 之后至1.0.6（9月19日至20日）

- 飞书：系统到飞书单向同步和配套通知/队列处理，不含反向写回。
- 版本：前后端统一迁入Raccoon-SalesBuddy仓库，明确主线与服务器版本。
- 团队：各页面读后端目录，使用稳定ID；启用且有权限的空团队也显示。
- 修复：团队组别显示、目录异常、FDE空团队目标误报无权限。
- 选项：分类、角色、优先级、阶段/等级等由后端返回，权限入口跟随后端。
- 地图：点象限空白处放大，再点空白处缩小，客户列表同步。
- 看板：全部团队或具体团队单选；我的保留部门/团队/个人分层。
- 登录：通用账号名＋密码；绑定手机后可手机＋同一密码。15个原邮箱账号改为大写前缀，原密码和权限不变。

未纳入错误的地图客户下拉筛选，也未混入额外CRM/Demo/Agent实验。

详细版本和上传状态见[1.0.6发行记录](../../docs/RELEASE_1.0.6_20260920.md)。

## 接入行为

自动保存同一账号、设备上尚未完成的录入；通过录入动作 ID 隔离草稿。
自定义返回支持保存或放弃；原文非空时显示“一键清空”，适用于手工输入、粘贴和转写，支持一次撤销。
已完成转写草稿恢复不重复拼接；清空或结束后的迟到回调按动作隔离。
正式归档只清理对应录入动作，避免删除后来创建的草稿。

后续按用户反馈调整：原文输入框固定为 440rpx 高度，长文本在框内滚动；清空入口不再依赖转写成功标记。
草稿目前没有独立列表入口，重新进入“记录客户拜访”会自动恢复当前账号在本设备上的未完成录入。

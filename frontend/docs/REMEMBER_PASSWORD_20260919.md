# 登录页记住密码

默认不勾选。用户主动勾选且登录成功后，仅在当前设备的小程序本地存储分别保留主动记住的账号与密码，打开登录页默认回填最近保存的一组。重新打开登录页时回填，密码默认隐藏；隐私同意仍需用户选择。账号支持邮箱或管理员已补录的手机号。

取消勾选只删除当前账号在当前 API 环境的已保存记录，保留本次正在输入的密码，不影响其他账号。点击「切换账号」清空输入和当前会话，并取消勾选，但不删除保存记录。手动修改账号时，完全匹配已记住的账号则回填对应密码，否则清空密码；大小写及首尾空格差异不算换号。

失败登录不保存；登录请求进行中取消勾选/切换账号，迟到结果不会恢复旧保存。强制改密时，完成改密后才保存新密码。不同 API 环境不会回填旧凭据；后台重置密码不可能主动清除离线设备缓存，但旧密码被服务端以 401 拒绝后删除该账号本地记录，用户须输入新密码。

存储键为 salesRememberedLoginV1，内部 version=2 按账号/API 分组，兼容读取上一版 version=1 单账号记录；与会话存储分离，普通退出登录不删除用户主动记住的凭据。它是用户选择的可回填本地存储，不是操作系统密码保险库，也不声称加密保护。不得记录、导出或提交实际账号密码。缓存读写异常不伪装为完成：保存失败提示用户且不阻止已成功的登录；清除失败提示重试并保留勾选状态。

输入账号前缀时，展示当前设备、当前 API 环境已记住的账号推荐，忽略大小写，最多 5 条；点击填入完整账号并回填对应密码。匹配列表只包含账号字符串，不包含密码。空输入、无匹配及完整账号不展开推荐。不请求公开账号目录，也不硬编码公司成员邮箱。

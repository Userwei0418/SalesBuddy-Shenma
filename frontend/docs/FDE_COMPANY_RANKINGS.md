# FDE 同级排名与统计接口

更新：2026-09-14。本文描述本轮源码已实现的契约与页面使用方式；不作为线上已部署或已验收的证明。运行版本与发布证据以仓库 `docs/CURRENT_STATUS.md` 为准，本轮整合范围见 `docs/SALESBUDDY_FDE_INTEGRATION_20260914.md`。

## 展示范围与权限

协作看板提供跟进数量、协助确收、Demo 场景登记数量三个同级榜单。榜单跟随统计周期，不随本人、指定成员、部门范围缩小。默认显示前五名，可展开全部；同值并列采用 1、1、3 名次。有效零值成员保留，未知值与零分开呈现。

普通 FDE 和 FDE 负责人均可读取普通 FDE 的同级汇总榜。服务端名册取当前工作区内有有效 `fde` 角色、有效 FDE 部门成员关系的账号；只有 `fde_lead` 角色的负责人不列入普通 FDE 榜。停用、删除或不再具备有效普通 FDE 身份的账号不在当前名册。

负责人当前授权部门的工作分布另用 `ranking`；全员同级榜必须使用 `company_rankings`。禁止将 `self/team` 的局部数据冒充全员结果，也不能通过遍历其他账号详情推算榜单。排名开放不授予同事的客户、商机、拜访全文或账本详情权限，前端同级榜不提供跨成员详情跳转。

## 指标定义

| 字段 | 本轮实现口径 |
|---|---|
| `followup_count` | 名册成员本人创建、本人记录并确认归档，归档时为普通 FDE 身份的拜访数；按拜访日期统计，新老客户均计入。销售在拜访中勾选协助 FDE 不增加此数。 |
| `opportunity_count` | 上述周期内本人归档记录关联的商机去重数，用于“我的—协作效率”的商机排名。 |
| `current_opportunity_count` | 当前有效协助关系下的商机去重数，独立于周期跟进商机数。 |
| `recognized_amount` | 当前有效协助项目在所选周期、截至今天的已确认且未作废确收账本金额，单位为元。 |
| `demo_scene_count` | 本人在所选周期创建、未删除的场景登记记录数；一条场景记录计一次，按创建日期归属周期。草稿、尚未提交的文本和已删除场景不计。 |

协助确收用于表示个人参与项目的经营事实，未实施个人贡献分摊。同一项目可出现在多名协助人的个人行中，不能把个人行金额相加当作公司确收。看板所选团队的总体确收另按项目集合及账本记录去重。

## 请求与响应

`GET /api/v1/fde/dashboard` 保留原有字段，新增同级榜。参数包括：

- `scope=self|team`；普通 FDE 仅本人，负责人可使用授权团队范围。
- `member_id` 或重复的 `member_ids`，仅缩小负责人有权读取的成员范围；不会缩小同级榜。
- `year`、重复的 `quarters`；空季度表示该年全年。
- `period=week|month|quarter|year|all`；周从周一开始，月/季/年使用自然周期。
- `date_from`、`date_to` 必须同时提供，结束日期包含当日；显式日期优先于自然周期参数。

时间归属统一采用北京时间。前端核验 `company_rankings.year/quarters` 与请求一致；实际日期边界可回读 `filters.date_from/date_to`。以下空数组仅示意结构，不是演示业务数据：

```json
{
  "company_rankings": {
    "data_source": "database",
    "scope": "all_fde",
    "complete": true,
    "year": 2026,
    "quarters": [],
    "start": "2026-01-01",
    "end": "2026-12-31",
    "total": 0,
    "items": []
  }
}
```

`items` 每条包含唯一 `user_id`、非空 `name`、`team_name`、`role` 及上表各指标。`total` 等于完整 `items` 的长度。后端输出真实聚合零值；前端保留对 `null` 的未知状态兼容，不把未知变为零或补出名次。

缺少 `company_rankings` 或范围、周期、完整性校验失败，只显示榜单未加载/错误状态，不改用模拟名册，也不清空其他看板内容。三个榜单的显示与格式校验位于 `miniprogram/utils/fdeCompanyRankings.js`。

## 相关统计区分

- `summary.period_visits`、`period_customers`、`period_opportunities` 是所选本人/成员/团队的归档事实。
- `summary.demo_scene_count` 是所选协助项目集合内的场景数；`own_demo_scene_count` 是所选成员本人登记数。两者不能互换。
- `ranking` 是当前所选成员的工作分布，包含任务、参与项目和金额事实，不是全员排名。
- `rhythm` 为 7 个日点，`rhythm_weeks` 为 12 个周点；结束于今天或所选历史期间的最后有效日期。没有记录的有效日期显示零，未来尚未开始的期间不造趋势。
- 六维画像不从这些排名合成总分，`overall_score` 继续为 `null`。

# 任务验收前端交接

## 本轮修改

- 接收人完成说明必填，他人任务按钮为“提交完成”；提交后等待发起人确认。
- 原发起人在任务详情查看完成说明，可确认或填写原因后驳回。
- 驳回后同一任务继续执行，不重新接受；每轮提交/审批历史可查看。
- 自建自领填写说明后直接完成；岗位候选人领取逻辑保持。
- 新增待确认和驳回通知卡片；旧卡片回读最新状态，待确认不从未完成列表提前移除。
- 完成说明、历史说明复用任务要求的 description 正文样式（25rpx、#4f6277、1.7 行距）。

## 依赖

后端分支 codex/task-completion-review-20260919，V104 数据库迁移。事件接口继续使用 POST /tasks/:id/events；complete=提交完成，新增 approve_completion / reject_completion。均带 version_no；驳回 note 必填。

本分支基于 a36003d，保留账号补全、多账号记住密码等已完成改动。不要用较旧后端分支中的 frontend 覆盖此目录。

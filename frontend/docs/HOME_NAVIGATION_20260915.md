# 多层页面返回总览

20 个非底部导航、非登录页面统一开启原生导航栏 `homeButton`，包括拜访录入、核对及归档成功页、客户详情、商机详情、待办详情等。左上角保留返回上一级，并提供主页图标，回到应用首页“总览”。5 个底部导航页面仍使用现有 tabBar；登录页保持现有自定义导航。

使用微信原生配置，让图标、点击区域、导航栏布局由客户端处理。原先在 5 个详情/列表页正文顶部重复显示的“返回 / 回到总览”横条移除。

依据：[微信页面配置 homeButton](https://developers.weixin.qq.com/miniprogram/dev/reference/configuration/page.html)，最低微信客户端版本 8.0.24。核对时直接读取官方页面确认支持；无需改成自定义导航栏，也不增加业务接口请求。

拜访原文和核对内容继续使用现有按账号保存的本地草稿；返回主页不代替人工确认归档。已归档内容已在后端保存。本轮未改变表单保存、质检、权限或后端行为。

验证：20 个子页面配置覆盖、26 个注册页面及 JSON/JS 静态检查，拜访录入、分阶段流程和 FDE 本人录入的 37 项既有定向检查通过。未执行页面自动操作或真机视觉验收；用户重新编译小程序后检查原生主页图标和跳转效果。

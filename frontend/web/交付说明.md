# SalesBuddy Web 1.1.0 · 本地完整交付

本包只更新 Web 销售工作台。业务基线为小程序 1.1.0（5f022c5），保留桌面工作区、连续创建客户、无客户语音卡片、全宽进度条和周报 Demo。小程序、管理后台、服务端均未改动；没有上传或部署。

## 启动已构建页面

需要 Node.js 22 或更新版本。在解压目录执行：

```sh
PORT=5188 node server.mjs
```

Chrome 打开 `http://127.0.0.1:5188/?mode=live#/pages/login/index`。macOS 也可双击「启动小浣熊SalesBuddy.command」。已有 dist，可直接启动，无需先安装依赖。端口占用时换一个 PORT。

企业登录继续使用同源 `/api/v1`；本地服务代理到 connection.config.json 中原中台地址。公司专属入口示例：`http://127.0.0.1:5188/?mode=live&company=公司码#/pages/login/index`。记住公司与账号，不保存密码。包内没有账号凭据，需使用实际授权账号。周报是独立 Demo，不读取真实周报数据。

## 隔离演示

```sh
PORT=5189 node scripts/start_department_preview.mjs
```

打开 `http://127.0.0.1:5189/?mode=preview#/pages/index/index`，顶部显示「合成数据演示」。此服务关闭真实中台代理，适合评审与测试。公司切换示例使用 `&company=demo2`；普通角色入口可选择销售、经理和 FDE。生成周报请用有跟进记录的销售身份。

## 从源码重新构建

另外需要 Python 3。依赖版本全部沿用锁文件，没有升级 React、Ant Design 或部门组件。

```sh
npm ci --ignore-scripts
npm run verify
```

修改后必须重新构建，不能只替换 dist。浏览器验证使用 Chrome 与外部 Playwright：

```sh
PLAYWRIGHT_MODULE=/绝对路径/playwright/index.mjs node --test tests/upgrade110.browser.mjs tests/customer-create-inline.browser.mjs tests/weekly-report.browser.mjs tests/account-session.browser.mjs tests/v106-visits.browser.mjs
PLAYWRIGHT_MODULE=/绝对路径/playwright/index.mjs node tests/upgrade110-smoke.browser.mjs
```

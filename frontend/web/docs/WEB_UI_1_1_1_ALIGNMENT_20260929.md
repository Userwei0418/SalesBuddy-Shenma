## 源码与构建

新通用组件为 `department-ui/WorkflowCompletion.jsx`、`advice-bridge.js`、`workflow-completion.css`。在现有页面 JSX 内接入；`index.jsx` 继续通过一次原模板渲染创建原业务子组件。

本次实际浏览器发现一个接线错误：可选布尔状态 `undefined` 被 helper 的默认 `true` 当作允许，导致折叠建议提前尝试组件初始化。两个父页面已显式传入 Boolean，并加入能力/折叠/晚到动作回归；没有用复制原业务处理器绕过。

构建命令（在 `frontend/web` 内）：

```sh
npm run build
npm test
PLAYWRIGHT_MODULE=/absolute/path/to/playwright/index.mjs node --test --test-concurrency=1 tests/workflow-completion.browser.mjs
```

`npm run build` 从本库 JSX 与只读业务源码生成 `dist/department-ui/app.js`、`app.css`、许可证摘要，以及 `dist/bundle.js` 和其余部署资源。部署使用完整 `dist`，不得手改产物后跳过源码构建。

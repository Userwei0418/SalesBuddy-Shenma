## 操作路径与观察

- 创建客户 → 连续填写/清空必填项：语音卡片消失，进度全宽且按实际字段变化；保存草稿后恢复空值和其他输入。四种视口截图 customer-create-*。
- 创建任务 → 选择负责人 → 团队、姓名/账号筛选 → 多选确认：独立任务请求，取消确认无写入；503 后保留人员/输入，重试维持相同幂等键。
- 任务详情 → 协调 → 选择候选人 → 原因 → 转交：稳定 ID、version_no 递增、操作历史可读；取消需原因与二次确认，已取消不显示 100% 完成进度。
- 任务详情合成待交接、待验收与收回取消资格：待交接不能完成；待验收没有直接取消入口；服务端 can_cancel=false 隐藏取消操作，没有试探性写入。
- 新增商机 → 输入 1000.123456 万元：显示 10,001,234.56 元；返回修改没有写入；公司阈值请求失败保留输入；确认保存 amount_confirmed_value 与 amount 一致。
- 客户页 → 不完整评分及更新失败：整图不显示不完整点位，失败可重试；成功后列表和点位数一致。桌面地图/列表约 42%/58%；窄屏上下排列，可滚动看到地图和列表。列表分页可见，展开长内容可滚动。
- 拜访 → 文本结构化 → 核对 → AI 质检 → 人工归档：草稿恢复/离开提示；归档 503 后保留质检内容与联系人，重试用同一请求与幂等键；成功后显示归档结果。
- 经营分析 → 摘要 → 展开完整榜单 → 收起：保持服务端范围和排名；截图 ranking-expanded.png。
- 公司链接 → 第二演示公司 → 切换：清理旧会话、返回需重新登录；账号测试验证旧 actor/退出响应不会覆盖新账号，强制改密仍受限。
- 周报 → 勾选更新 → 生成 → 编辑/复制 → 切换日期和刷新：选择与草稿保持；错误、空数据、重试、只取本人稳定 ID 均通过；始终是 Demo。

Chrome 覆盖宽 1440、1366、1024、390；客户地图及人员弹窗按这些宽度测试，创建客户与周报包含 1366×768、1024×600、390×844。键盘检查包括账号菜单 Tab 循环/Esc 返回焦点、人员弹窗 Tab/Esc、创建客户连续输入及中文输入法事件；任务二次确认焦点冲突已修复。并非全部页面在所有尺寸的全交互穷举。

## 包验证及未验证边界

最终 ZIP 用 scripts/package_department.py 打包，文件 CRC、逐文件 SHA-256、缺依赖时启动与本地模拟代理检查记录在 ZIP 旁「打包验证.json」。交付目录的「解压复验.json」记录最终 ZIP 解压后校验、按锁文件安装、重新构建和测试结果。

真实中台仅完成公开健康接口只读探测。线上 OpenAPI 版本、真实公司身份/RLS、Agent 输出质量、真实任务/商机/拜访写入、并发冲突、地图最终一致性和跨微信/Web 读回尚未验证；需要授权测试公司后联调。没有向真实公司创建、取消或更新任何测试业务。

包中历史浏览器脚本没有全部重跑；本次清单以以上脚本/日志为准。未进行真机软键盘、全量屏幕阅读器或完整对比度审计；有限轮询上限和部分复杂角色场景主要由冻结原包单元测试覆盖，不将其称为全量 UI 或生产验收。

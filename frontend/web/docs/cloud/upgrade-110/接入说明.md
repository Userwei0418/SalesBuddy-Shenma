## 重点契约

| 场景 | 现有接口 / 字段与约束 |
|---|---|
| 公司入口 | GET /auth/company-entry?company_code=…：公开精确查询；登录公司名/码显示使用返回值。不把它当作公司目录。切换公司先使旧会话失效再重新登录。 |
| 登录 | 原账号登录、actor/权限、强制改密与退出接口。新版 salesAccountHistoryV3 只记公司/账号；legacy salesRememberedLoginV1 中旧密码按原逻辑清理。 |
| 选人 | /directory/members、/tasks/recipients、/tasks/{task_id}/reassignment-options；items/teams/defaults、稳定人员 id、account_code、team_ids；无权限和无候选人区分，不用姓名代替 ID。 |
| 多人任务 | POST /tasks/batch，tasks 中每个接收人对应独立任务；关联类型、客户/商机、截止时间、优先级均走 taskCreateBody；重试维持原 Idempotency-Key。 |
| 取消/转交 | POST /tasks/{task_id}/events；event_type、note、version_no、assignee_account_code；保留服务端 can_cancel、can_coordinate、action_permissions、handover_required 和历史 previous_owners/new_owner。待验收先驳回再取消，不能绕过该规则。 |
| 商机金额 | GET /company-rules/presentation；opportunity_amount.definition.schema_version=1 与 warning_threshold_wan。万元字符串按原精度换算成元；提交 amount、version_no（编辑）及必要时 amount_confirmed_value，确认值必须等于本次完整金额。每次相关保存读取当前公司阈值，失败不使用猜测默认值。 |
| 地图 | GET /customer-assets/map 与 POST /customer-assets/map/refresh；items、activity_since、as_of、potential_score、relationship_score。以服务端当年正式跟进窗口为准。更新返回 ready/updating；不完整不拼凑点位，3 秒轮询，最多 10 轮，离开页面停止。资产 summary 使用完整授权范围单独展示。 |
| 拜访 | 原 /visit-flow/structure、/visit-flow/quality、/agent/runs/{id}、POST /visits、PATCH /visits/{id}。保留 source_run_id、质检快照、collaborator_ids、fde_participant_ids、_quality_review_run_id、_opportunity_mutation、version_no、日期与空值处理。AI 草稿经人工确认后归档。 |
| 经营分析 | /dashboard/rankings；contract_version=2，data_source=database，scope=peer 或 company_teams。selected 范围与当前查询匹配；个人同级排名，公司团队榜；团队跟进人均口径，空成员不造排名。 |
| 权限与隔离 | 服务端 actor/capabilities/permissions、对象 action_permissions 与原生 identity/serial/write context 为准；账号/公司切换使旧请求和草稿所有者失效。Web 不授予新的真实能力。 |
| 周报 | 仅 Web Demo，本次无真实周报接口、不新增字段。 |

## 适配文件

- NativeDialogs.jsx 将最新原生选人和取消事件接入 Ant Design；TaskCreate/Tasks/TaskDetail 传递原组件状态。
- OpportunityCreate.jsx 复用 opportunity-form；VisitConfirm 与商机编辑入口共享同一金额处理。
- browser-platform.js 仅将账号历史映射到持久存储，认证与业务草稿仍按原 Web 会话隔离；runtime.js 传递公司入口参数，scripts/web_api_module.py 保留旧请求隔离。
- preview-api.js / preview-workflow.js 只服务 mode=preview；不会在真实接口失败时偷偷替代真实结果。自动化的金额阈值、角色、任务和公司均是合成样本。

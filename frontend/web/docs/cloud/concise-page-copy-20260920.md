# 页面文案精简

## 目标

按用户截图和明确要求，常规页面不再常驻统计解释、操作教学、重复副标题和模板化动态摘要。保留页面名称、业务事实、字段/单位、状态、错误与操作确认，业务逻辑不变。

## 实施

1. `department-ui/Home.jsx`、`Customers.jsx`：去掉指标解释、重复范围说明、排序教学和地图操作说明；动态列表保留标题、变化事实、状态、时间、动作，完整回执按需展开。
2. `department-ui/Tasks.jsx`、`TaskCreate.jsx`：去掉类型/字段教学和流程介绍，压缩输入占位提示；保留提交校验和原确认。
3. `review-pages.js`：审查其他原生页面，用逐页面明确节点规则清理同类文案；不修改小程序共享源，不用全局`.note`/`.hint`隐藏规则。
4. 构建、共享源完整性与现有关键浏览器回归；检查桌面与窄屏。更新候选分支与截图记录。

## 边界

用户后端返回的拜访正文、任务描述、风险依据、对象信息不作为“解释性文案”删除。数据缺失、加载失败、无权限、AI建议来源及可能产生真实操作的确认仍需可见。四象限名称和坐标轴保留，教学句收起。

## 验证

执行 `npm run verify` 与受影响的客户、总览、任务和表单浏览器检查。仅使用合成数据测试；本轮不提交真实业务写入。

## 当前结果

- 总览及原展示层回退状态：去掉统计说明、指标副文案、重复的动态摘要；保留变化事实与完整回执。
- 客户列表、认领、新建、维护、详情及商机列表、新建、维护、详情：清理教学和重复副标题，保留字段、金额、数量、风险与只读状态。
- 任务列表、创建、详情：去掉排序教学和字段说明，保留已选条件、收件人、校验、完成说明和验收动作。
- 拜访录入、质检、归档、详情，Demo、风险、经营分析、个人/成员成长及 FDE 组件：同类常驻说明清理；经营分析完整数据口径默认收起，AI 来源、分析状态、建议与证据保留。
- 登录：精简营销段落与账号说明，并移除对应的旧节点初始化引用；记住密码、隐私、首次改密、错误和找回入口保留。
- 没有说明文字的页面不额外改变内容；不以通用样式名批量隐藏信息。检查覆盖26页和14个原组件，当前四个 React 页面单独适配。

验证记录：`npm run verify` 通过（117项，含12项渲染规则保护检查）；256份共享业务源完整性校验通过。53项相关浏览器回归已通过，覆盖总览/客户10项、任务8项、登录13项、商机与认领列表14项、客户与商机表单8项。地图用例等待 React 绘制后读取点位；表单用例等待页面运行对象就绪，避免加载竞态导致误报。

另外检查了五个原页面的实际截图、拜访关联前置状态与禁用按钮、经营分析数据口径展开/收起，以及1366px和390px的四个组件库页面。测试均使用隔离合成数据，不构成正式账号权限、后端写入或生产验收。

# SalesBuddy Web · 创建客户与周报 UI 优化

交付日期：2026-09-24。基线：用户提供的 `SalesBuddy-Web-v10 (1).zip`。

本包包含完整前端源码、已经构建好的 `dist/`、测试和核对记录。此次仅生成本地交付包，没有上传、发布、部署，也没有修改原工程。交付包在独立副本中整理；覆盖副本文件前均重新读取、保存时间戳备份并比对，写入后再次读取核对。

## 本次界面改动

1. **创建客户**：字段直接在页面中连续填写；保留动态选项、团队稳定 ID、原校验、草稿和提交处理。删除该页「语音填写客户信息」卡片、开始入口和专用样式。顶部左侧显示实际必填完成数，右侧显示待补充数；下方进度条铺满可用宽度，按实际数量变化。其他页面的语音功能保持原样。
2. **周报 Demo**：在「经营复盘」下，与「经营分析」并列增加「周报」。左侧查看本人最近 7 天（含今天）或上一个自然周上传的合成跟进记录，支持搜索、勾选、查看原始内容与刷新；右侧一键生成结构化周报，可编辑、复制，并在当前标签页按账号和周期暂存草稿。已有人工编辑时，重新生成需确认。

周报当前只在 `mode=preview` 示例工作区读取合成数据；正式模式不会发起周报数据请求。周报由前端规则整理，未接入 AI，也未新增正式中台接口、数据库字段或周报保存接口。正式对接是后续独立工作。

## 本地查看

需要 Node.js 22+。解压后进入包根目录，直接使用已构建产物预览，不需先安装依赖：

```sh
PORT=5190 node scripts/start_department_preview.mjs
```

创建客户入口：`http://127.0.0.1:5190/?mode=preview#/pages/customer-create/index`

周报入口：`http://127.0.0.1:5190/?mode=preview#/pages/weekly-report/index`

该示例服务主动关闭后端连接。正式账号运行方式仍是原有的 `node server.mjs`，使用包内原连接配置，详见根目录 `交付说明.md`。

后续开发首次安装依赖需访问包地址：

```sh
npm ci --ignore-scripts
npm run verify
```

浏览器检查另需可用的 Playwright 与 Chrome：

```sh
node --test --test-concurrency=1 tests/customer-create-inline.browser.mjs tests/weekly-report.browser.mjs
```

可通过 `PLAYWRIGHT_MODULE` 指向 Playwright 模块；通过 `CUSTOMER_INLINE_SHOTS` 和 `WEEKLY_SHOTS` 指定截图输出目录。

## 本次改动

- 状态文字和标签恢复红、黄、绿；移除待办、风险及首页原来的黑底状态覆盖。
- 个人页六维能力分数条统一为主蓝色，原分数、长度、阈值和状态文字保持。
- 首页业务卡没有状态标签时，去掉多余的“数据已同步”提示；真实状态标签保留。

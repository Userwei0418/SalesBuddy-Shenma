# 神码测试范围

保留销售业务、鉴权、权限、数据库迁移、管理端和小程序测试。通用公司开通、账号改名、发行包验证和 AI 验收工具一并维护；默认数据库改为神码，开通口令只执行当前统一密码规则。

未移植以下商汤一次性运维/演示脚本及其专属测试：历史组织调整、指定 FDE 部门开通、预设人员的演示跑数脚本、原环境现场 FDE 拜访验收脚本。它们依赖原组织或旧现场约定，客户环境采用 deployment/ 下的新建实例与验收入口。销售 API 及普通 Worker 中的 FDE 业务功能保持保留。

数据库集成测试须连接一次性测试数据库；不能对客户业务数据库或商汤数据库运行全量种子/回滚夹具。本地无测试库时，测试会显式 skip 集成部分；实际部署另记迁移、运行角色和受控客户账号验证。

另不携带原服务器部署脚本、原中台发布绑定的专属测试，以及基于原演示公司/场景清单的现场验收脚本测试。新部署位于 deployment/，不复用原服务器路径、systemd 服务名或 publication.json。被排除的测试仅针对这些未移植工具；backend/src 的业务模块与对应测试均保留。

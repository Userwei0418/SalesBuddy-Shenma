# 神码独立部署计划

## 目标

建立独立本地目录与私有 GitHub，部署销售系统和中台，完成客户环境下的业务链路。商汤代码、远程仓库、数据库、小程序与发布流程不受影响。

## 步骤与验收

1. **项目隔离**：固定销售 1.0.8 / V125 和中台 20260923 来源；只保留源码、系统配置及合成测试，不复制真实环境证据/绑定；新仓库无商汤推送目标。
2. **环境准备**：再次核对两台空白系统、盘空间、网络、依赖源；安装到独立路径，保留失败日志，不覆盖已有业务。
3. **中台安装**：Docker Compose 17 服务、空实例、HTTPS 本机验证、独立管理员；镜像下载/服务就绪与模型验收分别记录。
4. **销售安装**：Python 3.12+、本机 PostgreSQL、V125 迁移、最小权限、初始公司和管理员、API/Worker；受限真实账号验证读写及拒绝越权。
5. **域名与联调**：确认两个 443 入口正确分流、可信证书；新中台发布销售 Agent，客户模型配置后验证真实调用和业务输出。
6. **小程序**：收到客户 AppID 后配置，合法域名、真机登录/录音/上传与业务链路验收；未经独立授权不提交正式审核。
7. **交付**：源码/镜像/迁移/进程版本、备份恢复、部署说明、独立定开工作流完整登记。

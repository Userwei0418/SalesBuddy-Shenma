## 使用与验收边界

用现有销售账号登录，进入「经营复盘 → 周报」，选择本周或上周，生成后核对正文并保存。周报归属自然周；素材窗口为对应截止时间向前 14 个上海自然日，以上传时间取数。小程序本次不新增周报入口。

技术生成与保存链路已验证。客户真实跟进记录下的正文质量仍由销售核对；本次合成素材验收不等同于客户业务验收。中台 API 未返回实际运行快照 ID，因此 `runtime_snapshot_verified=false`，不能把配置中的期望快照当成实际运行版本证明。新增商机字段、跟进类型／关联业务与 CRM 同步继续等待正式业务映射，不在本次周报接续范围内。

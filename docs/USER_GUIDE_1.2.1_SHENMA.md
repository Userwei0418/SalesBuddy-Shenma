## 角色与范围

- 销售：处理本人授权范围的客户、商机、跟进、任务和报告。
- 主管：在授权团队范围查看、协调业务，并处理获授权的任务或认领审批。
- 销售总经理：按公司授权查看组织汇总、成员业务与经营分析；不会自动获得其他公司的数据。
- 运营／系统管理员：直接打开运营后台 /admin 登录，维护组织、账号、权限与建档审批。仅有后台授权的账号不会进入业务 Web 或小程序，属于现有权限设置；直接建档等操作保留给具有对应权限的账号。
- FDE／FDE 主管：按当前既有授权从神码小程序使用，录入授权商机的跟进并查看协作业务。本次不因升级额外开放业务 Web，也不自动授予销售商业字段修改权。
- 页面、操作和数据范围取服务端有效授权。菜单不可见或操作被拒绝时，由企业管理员核对具体权限，不通过换入口绕过。

## 新版工作区

- 电脑端通过侧栏进入工作台、客户、商机、拜访与跟进、任务、工作报告和经营分析；按当前权限显示入口。
- 顶部范围、日期、人员和搜索条件用于当前页面。切换页面时先核对正在查看的公司和范围，避免将本人和团队统计直接比较。
- 客户与商机提供紧凑筛选、表格列和详情入口；窄屏可展开筛选并横向查看表格。
- 商机看板使用保存在服务器的方案。进入“商机经营”或点击看板的“编辑方案”，配置显示字段、组合条件和展示方式，保存后可在“商机看板”切换，也可设为自己的默认看板。个人、团队或公司可见范围以账号实际授权和页面可选项为准。
- 共享方案只共享查看配置，不会增加任何人的商机数据权限。保存失败以页面错误为准；切换方案前先保存需保留的修改。旧方案若提示需要重新配置，按提示调整并保存后再使用；删除方案不删除商机数据。
- 账号菜单用于查看账号、修改密码或退出；账号切换后重新加载当前授权范围。

## 客户申请、建档与认领

- 先搜索客户。业务 Web 在“客户认领”页可选择“未找到客户？申请建档”；小程序从具有权限的客户建档入口进入。
- 无直接建档权限、但有申请权限的账号看到“客户建档申请”。按当前服务端选项填写企业身份、客户资料、目标团队和联系人，核对后提交。
- 新版允许客户、合作伙伴及兼具两种身份的企业。选项来自服务器；历史失效选项需要重新选择，不能把旧标签自动视为新值。
- 业务 Web 的建档页显示“我的新建申请”，可核对待审批、通过和驳回结果及原因。小程序本次提供申请提交，完整申请进度请在 Web 查看。
- 运营或管理员在后台“建档审批”核对申请并批准或驳回；驳回后按原因修改资料重新提交。
- 审批通过后建立待认领客户，**申请获批与客户认领是两步**。回到客户认领目录选择客户，再按现有认领审批流程处理。
- 有直接建档权限的运营继续使用直接建档入口。具体必填字段以当前页面与后台要求为准；本次不把旧 S2 实验的独立公司编号控件、撤回按钮当作新版现有入口。
- 客户来源、名称或编号疑似重复时，先搜索核对已有资料；建档或认领失败时检查提示与已有记录，避免重复提交。

## 商机与客户经营

- 从客户或商机工作区进入已有记录，并按权限新增或维护商机。先确认客户和负责人，再填写阶段、金额、预计关单时间及计划。
- 金额以页面标注的单位为准；万元输入与后端元字段会转换。确收、回款预测与实际业务数据分开，留空不等于零。
- 产品线由意向目录或交易物料形成；已有交易物料时按物料归属显示，不能另外填入矛盾的产品线。
- 30% 及以上阶段需要完整季度计划时按页面提示补齐；赢单、丢单、重新打开和大额修改需要明确确认。
- 协助 FDE、主责人员、参与者及补充字段依权限维护。负责人目录中的姓名不代表可以读取该人的全部业务。
- 保存超时后使用“查询原保存结果”等恢复入口，确认原提交状态后再操作。不要直接再次新建同名商机。

## 跟进记录与任务

- 录入跟进时先选择客户，按实际需要关联商机，填写或语音整理沟通内容、下一步计划、日期及联系人。
- 语音整理得到草稿后先核对，再执行质量审核和人工确认归档；生成成功不等于正式记录已经保存。
- FDE 仅使用本人可录入的商机范围，不能借跟进表单修改无权维护的销售字段。
- Web “拜访与跟进”支持日期、人员、客户及商机筛选；打开详情核对完整内容。页面错误不等于零记录，先重试或缩小范围。
- 新建任务时填写责任人、截止时间和关联业务。接收、执行、提交完成、审批或取消按任务当前状态和账号权限进行。
- 同一任务或跟进读取失败时先核对原记录；不要依靠重复创建解决状态不确定。

## 工作报告

- Web 进入“工作报告”，可查看日报、周报、双周报、月报与季度报的实时汇总，按授权选择个人、部门或成员。
- 实时概览与已保存报告文档不同：切换周期会重新取数，生成文档则冻结其材料和方案。核对日期、范围、来源和缺失信息后再生成。
- 可使用方案组织报告内容，查看生成状态、编辑正文、保存修订、查看历史与来源；复制、下载和共享按独立权限开放。
- “共享”只按选择的成员／团队／公司范围共享已确认修订。编辑后尚未再次共享时，接收者仍看到此前的共享版本。
- 生成任务进行中或结果不明时先读状态。保存失败保留本地编辑；“保存结果待确认”时使用核对入口，不重复提交。
- 会议模式、Review 和经营概览等聚合展示用于经营讨论；数据仍受原始授权范围约束。它们与飞书发布能力分别控制。
- 小程序保留移动端跟进和既有周报入口；完整多周期报告工作区、方案配置和本文的新飞书发布入口以 Web 为主。

## 飞书同步、群通知与回执

- 已归档跟进仍通过神码已有飞书配置同步多维表格并向已配置群聊推送，企业应用、表格和群绑定升级时保留。
- 对于新版已保存的工作报告，作者在文档页使用“同步飞书并推送群”，核对报告名称和修订后确认。不会因为生成草稿或编辑正文自动发群。
- 发布要求作者身份、共享能力、最新已保存修订，以及后端确认来源可发布。存在未保存修改时先保存。
- 每份文档只冻结发布一次，后续编辑不会自动覆盖飞书或再次推送；需发布新的报告时应先完成新的业务文档并重新核对。
- 页面分别显示“多维表格”和“群通知”状态。入队仅代表已接受任务；“已入表”和“已推送”分别依据各自回执。
- 入表成功而群推送尚未完成时，刷新飞书状态或请管理员检查任务。结果未知时不会自动重复发送；不要用反复点击制造通知。
- 遇到版本冲突，重新读取报告后核对。提交超时且状态也读不到时显示“待核对”，不能据此断言未发布。
- 演示、测试或来源无法完整核验的报告禁止发到正式飞书。普通报告，以及包含 Review、经营概览或会议事实的报告，都以当前文档的实际来源校验和发布状态为准；报告类型本身不等于已具备发布资格。只有作者有共享权限、来源可核验且不含体验数据、企业飞书配置有效时，页面才允许确认发布。
- 旧周报同步链路与配置继续保留。本次没有新增日报、月报等周期的自动定时群推送；新入口由作者手动确认。

- 后台用于公司组织、成员、角色、审批和业务运行管理；中台用于 Agent、知识库与模型运行管理。两者职责不同，登录账号和权限也可能不同。

- 更换时按页面先验证连接再更新，完成后核对模型功能。中台无需另行复制填写同一密钥；业务组织仍由神码管理员管理。

# 神码 SalesBuddy 使用说明（1.2.1 适配版）

## 1. 适用范围

本文面向神码销售、主管、销售总经理、运营管理员和中台管理员。当前神码线上仍是 `094841a` / `V159`；本文件是 1.2.1 适配后的使用说明草案，正式上线后需将版本回执补入文档首页。

2026-10-15 的 S2 客户建档申请已完成本机隔离验收；S3 个人商机视图也已完成本机隔离验收。以下新增入口只适用于对应隔离候选，线上没有本次新增入口。新 PC 界面已完成本批隔离验收；它承接 S2/S3、工作台、跟进记录和原周报。CRM、完整商机工作区、工作报告 V3 等仍按配套批次推进，不能据本手册视为线上已开放。

## 3. 账号和权限

1. 销售：查看和维护本人权限内的客户、商机、跟进和任务。
2. 主管：查看本团队数据，处理团队范围的审批和跟进管理。
3. 销售总经理：按公司授权查看销售组织范围的客户、商机、跟进和经营汇总。
4. 运营管理员：维护组织、账号、权限、审批、演示数据标记和运行配置。
5. `smAdmin`：神码运营/管理专用账号，负责后台和中台管理，不用于日常销售录入。
6. 中台管理员：管理 Agent、知识库、模型连接和中台运行状态；不能绕过销售后端权限直接改客户或商机。
7. 模型 Key 只允许在运维后台的模型服务配置入口更换，页面不回显完整 Key；普通业务账号不显示该入口。

## 4. 销售日常操作

1. 登录后先进入客户列表，使用搜索、团队范围或负责人筛选查找客户。
2. 在客户详情中查看关联商机、跟进、任务和历史记录。
3. 新建商机时填写客户、阶段、金额、预计时间、产品线和下一步计划；1.2.1 适配后可使用产品线或物料目录时，以页面实际开放字段为准。
4. 录入跟进时先选择客户，再按需要关联商机，补充跟进内容、下一步动作、时间和参与人员。
5. 保存后检查详情页是否生成唯一记录；遇到网络超时先刷新或进入记录列表核对，不要直接重复提交。
6. 任务可从商机或跟进中创建，填写负责人、截止时间和协作人员；涉及团队管理的任务按主管或管理员权限执行。

## 5. 客户建档和认领

1. 在小程序或业务 Web 的客户页选择“客户建档 · 申请与进度”，进入“填写申请”。标准销售、主管和销售总经理角色均可提交本人申请。
2. 填写客户名称、公司客户编号 / 审批单号、归属团队和联系人等资料。编号由申请人和运营核实，本批没有自动对接集团 CRM。
3. 提交后在“我的申请”查看待审批、已通过、已驳回和已撤回状态。审批前由本人撤回；被驳回后依据原因补充资料并重新提交。
4. 运营或管理员在销售后台的“建档审批”处理申请，驳回必须填写原因。标准销售和主管不能审批建档；有旧直接建档权限的运营继续使用原入口。
5. 通过后客户进入待认领池，申请人可点击“前往客户认领”，按原流程另行申请。建档通过不会自动绑定客户归属。
6. 保存失败会保留输入，按页面提示重试；重复名称或公司编号应先核对已有客户。请勿为了绕过查重修改名称或编号。
7. 本批保留自定义角色和账号例外授权，具体入口以管理员授予的权限为准；详细验证见 S2 验收说明。

## 6. CRM 数据使用规则

1. CRM 是客户和商机主数据来源，首期以读取和同步为主。
2. CRM 数据进入 SalesBuddy 前按 CRM 唯一编号匹配，不能只按企业名称匹配。
3. 首次导入后再同步新增、修改、负责人调整和阶段变化；删除、转移和失效记录按双方确认的规则处理。
4. SalesBuddy 中的跟进记录是否回写 CRM，必须以集团 CRM 对接方提供的接口、权限和回执规则为准。
5. 如果字段无法确认，保留为空并进入待核对清单，不用默认值代替真实业务事实。

## 7. 飞书同步和通知

1. 销售录入并保存跟进记录后，由后台同步到神码指定的飞书多维表格。
2. 需要群通知的事件由飞书 Worker 推送到神码指定群聊；推送失败可在后台查看状态并重试。
3. 周报生成后先在 SalesBuddy 中核对内容，再按权限发布到飞书多维表格或群聊。
4. 演示数据和测试账号产生的跟进、周报不得进入正式飞书表格、正式群通知或正式销售评估。
5. 飞书表格、群聊、应用身份和 Key 属于神码自己的配置，升级时只迁移程序能力，不替换绑定。

## 8. 周报使用

1. 进入“周报”入口，选择报告周。当前神码周报按本人素材生成；新版多角色、多周期报告仍待配套。
2. 先查看材料来源，确认客户、商机、跟进和任务数据范围正确。
3. 生成草稿后检查事实、金额、阶段和下一步计划，必要时编辑后保存。
4. 发布前确认收件范围和是否包含演示数据；确认后再执行飞书发布或群推送。
5. 如果生成长时间没有结果，不重复点击生成；先查看任务状态，必要时取消并保留失败记录，等待管理员处理。

## 9. 演示数据规则

1. 演示数据在后台按 `data_kind=demo/test`、`import_meta.synthetic_trial` 及试用批次标识，普通销售页面不添加“演示”前缀；关联跟进、商机和任务继承来源边界。
2. 演示客户、商机、跟进和任务只能在隔离演示公司或明确的试用批次中使用。
3. 模拟金额不能作为真实销售预测、确收、回款或能力评估事实。
4. 清理演示数据必须按批次和后台回执执行，不能按名称模糊删除，也不能删除已产生真实业务关联的记录。

## 10. 管理员维护

1. 新增或停用账号前，确认公司、团队、角色、数据范围和账号额度。
2. 修改权限后使用该账号实际登录检查可见范围，不能只看后台保存成功提示。
3. 更换模型 Key 前先在运维后台验证连接，再发布生效；Key 不通过聊天、日志或前端传递。
4. CRM、飞书和中台配置修改后，分别执行一次只读健康检查和一条隔离测试链路。
5. 升级、迁移和清理演示数据前先做数据库、运行配置和批次清单备份。

## 11. 版本和问题反馈

1. 反馈问题时提供入口（小程序、Web、后台或中台）、账号角色、操作步骤、发生时间和页面提示。
2. 不在群聊或工单中发送密码、完整 API Key、Cookie、Token、数据库连接串或客户敏感数据。
3. 版本升级后以后台版本信息、健康检查、迁移回执和隔离验收结果为准，不以源码目录时间或浏览器缓存判断已上线。

## 12. 个人商机视图（S3 隔离候选）

1. 从电脑端销售工作区进入“商机”。先设置搜索词、团队、负责人、阶段、等级和时间等筛选条件，再选择显示字段、排序及分组。
2. 点击“保存为新视图”，填写名称。个人视图保存在当前公司、当前账号下，换用同一账号登录后可重新选择；本批不提供团队共享。
3. 选择已保存视图时，一次恢复显示字段、组合筛选、排序和分组。视图只改变查看方式，记录仍由服务器按当前授权筛选。
4. 调整后选择“更新当前视图”保存；“重命名”只修改名称，不覆盖原筛选配置。删除视图不删除商机。
5. 加载或保存失败会显示错误，不能把本地临时显示当成保存成功。同一账号多页面同时修改出现版本冲突时，先刷新视图再核对，避免覆盖另一页面的更新。
6. 若保存的团队或人员不再在授权范围内，以当前权限为准；管理员扩大业务权限之前，切换视图不会增加可见数据。
7. 小程序本批沿用现有商机筛选，不增加电脑端的完整个人视图编辑器。


## 13. 新版 Web 工作台与导航（隔离候选）

1. 登录后进入“工作台”，顶部快捷按钮按当前账号权限显示。侧栏可折叠；折叠不会丢失分组展开状态。
2. “跟进概览”的周期与本人/部门/成员条件只作用于该区域。上方原任务概览保留自己的统计口径。点击跟进、客户或商机指标，可带着条件进入跟进记录。
3. 客户和商机页面把常用筛选放在工具栏；屏幕不足时从“更多筛选”展开。表格按当前权限显示，分页可滚动访问。
4. 商机页面点击“视图设置”选择和排列字段、设置排序或分组。保存为个人视图后可再次恢复。私人视图不会扩大可读数据范围，也不会共享给其他账号。
5. 运营管理后台只向有相应权限的账号显示；新导航不会额外授予后台或中台权限。
6. 窄屏使用顶栏账号图标查看账号、修改密码或退出；桌面使用侧栏底部账号入口。原有全局“新增商机”入口仍保持关闭，需要维护商机时从已有客户/商机业务流程进入。

## 14. 跟进记录（隔离候选）

1. 在侧栏选择“跟进记录”，录入新内容仍从“记录拜访”进入。
2. 选择今日、本周、双周、本月、本季度或自定义日期，再按权限选择本人、部门或成员。这里按实际跟进日期统计；周报素材仍沿用原来的系统上传日期口径，两者不能直接比较为同一数字。
3. 可按时间、人员、客户、商机或表格查看。搜索会交给服务端匹配完整跟进内容；客户和商机选项来自当前已读取的结果。
4. 列表展示摘要，点击“详情”读取完整内容。关联客户或商机链接只有当前具备读取权限时才可打开。
5. 一条跟进涉及多个商机时，跟进条数只计算一次；活跃客户按所有可见关联客户编号去重，伙伴不算客户。
6. 读取失败时页面显示错误，不将错误当作零记录。重试仍保留条件；记录过多导致未读取完整时，缩小时间或人员范围。
7. 切换账号或权限变化后，旧账号的记录与详情会清除。目录中的候选姓名不代表获得该人的业务权限。

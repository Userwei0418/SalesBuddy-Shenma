## 后续替换

销售管理后台的“模型接口配置”（`/admin#modelApis`）已有按文字、转写、合成用途配置服务商名称、完整接口地址、模型和 Key 的能力。修改先测试，再发布生效；密钥不在响应和配置快照中明文展示。当前环境默认值来自 `/etc/shenma-sales/runtime.env`，属于调试初始配置；通过管理后台发布的公司配置可覆盖它。

中台已安装经官方市场校验的 OpenAI-API-compatible 0.0.67 插件，并已保存和验证 SenseAudio-S2-Lite 连接。后续通过模型供应商配置页面更换接口地址、模型和 Key。当前中台调试配置的上下文窗口为 32,768、输出上限 4,096，属于本实例的配置值，不作为供应商模型最大容量承诺。销售与中台分别维护各自的连接配置，替换供应商时需核对两边，不能只改其中一处。模型切换不需要改小程序源码。

正式交接时由客户配置自己的 Key；本次调试 Key 不表示正式额度或长期供应商承诺。更换后须重新测试文字、转写和已发布 Agent 的真实调用。

依据：https://docs.senseaudio.cn/api-reference/introduction

### 2026-09-24 调试修正

客户经营建议提示词新增逐条事实核对：已有非空描述不能称为空，未提供字段不能推断不存在；只有基础档案且无经营资料时返回空建议。新版本已发布，三组合成回归（空经营资料、已有描述、资料夹带指令）均返回空建议，未再复现上述错误。这是本轮样例验收，不保证任意模型输出无误。

销售后端新增 `AGENT_FDE_CA_BUNDLE` 可选配置，只对中台 HTTPS 客户端使用指定证书信任文件，保留域名校验并继续忽略代理环境变量。客户临时证书位于销售机 `/etc/shenma-sales/agent-ca.pem`。正式证书到位后清空该配置，恢复系统公共 CA 信任；证书变化需重新核验，不能关闭 TLS 校验。此配置不改变浏览器或小程序的证书信任。

候选客户端已在销售服务器以实际服务用户（UID 998）调用中台 `/parameters` 与聊天接口，完成证书校验、事件流解析及空资料返回校验。候选代码尚未作为运行版本发布，销售业务绑定尚未启用。

补充正向样例：按销售后端真实 facts 结构提供一条试点拜访记录，使用后端 `messages()` 生成本次提示及允许引用；模型返回一条确认试点范围、验收标准和负责人的建议，引用给定拜访 ID，通过 `validate_advice()` 校验。仅覆盖合成调用，尚不等于登录后的客户业务闭环。早期把拜访信息放在非标准 subject.latest_followup 字段的测试返回空建议，未作为正向通过证据。

## 第五轮（同日）：穿透页统一到设计规范

看的人反馈：我的、客户详情、商机详情、客户认领、经营分析这些穿透页还是旧样式。这轮不逐页重写，而是在 Web 构建里加一道「设计系统皮肤」（scripts/build.py 的 design_skin），小程序页面样式进 Web 时统一处理：

| 项 | 处理 |
|---|---|
| 字号 | 小于等于 24rpx（12px）的一律取 `--ui-text-small`，不再有 10px、11px |
| 渐变 | 全部改平色：取渐变第一个色标，近白或透明的换成 `--ui-surface`，其余保留原色再映射变量 |
| 写死的颜色 | 常见蓝、灰、墨、线、浅底共 60 多个十六进制值映射到 `--ui-primary / --ui-ink / --ui-muted / --ui-line / --ui-selected / --ui-surface-subtle` |
| 页头 | 页名型的 hero 标题、英文 eyebrow、面包屑重复的标题全部隐藏（创建客户、记录拜访、风险中心、客户认领、资产明细、商机看板、核对拜访）；对象名型的标题（任务详情、风险详情）保留 |
| 我的 | 页签改为下划线式，头像与指标卡不用渐变，退出按钮圆角统一 |
| 客户资产明细 | 深蓝渐变大卡改为白卡描边，数字主色 |
| 风险中心 | 去掉暖色底和径向渐变 |
| 记录拜访 | 顶部「拜访怎么填写」折叠说明去掉 |

新增 `legacy.css` 放这些页面级补丁。共享的小程序业务代码未动，`npm test` 117 项通过。

还没做的：我的（营销效率、销售画像两个页签的图表）、客户详情、商机详情仍是旧展示层加皮肤，没有换成组件库；要换成 SbTabs、SbDetailLayout、SbField 需要逐页重写，建议下一轮按访问量排序做。

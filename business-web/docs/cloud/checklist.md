## 当前偏差与后续整改顺序

以下依据现有源码抽查，未将所有 CSS 声明都判为缺陷；具体页面须检查最终生效样式。

| 编号 | 涉及区域／规则 | 现状依据 | 后续处理 | 状态 |
|---|---|---|---|---|
| D-01 | 首页、详情、旧桌面样式 / V-01、V-03 | 2026-09-20 高频页面、任务列表、登录/导航原声明已迁到共享变量；少数布局量保留 | 专项旧页继续逐页检查 | 本轮范围已整改 |
| D-02 | 辅助文字 / V-02、V-04 | 2026-09-20 高频页面辅助字统一到12px，桌面/短屏/320px回归通过 | 未改造专项页面仍需逐页检查 | 本轮范围已整改 |
| D-03 | 多层覆盖 / G-02 | desktop.css、visual-theme.css、theme.css 与各页面 CSS 仍有层叠覆盖和 !important | 每次页面改造时删去被完全取代的规则，禁止新增第二套全局主题变量 | 持续迁移 |
| D-04 | 五类页面模板 / T-01～T-05 | 示例模板使用原生语义 HTML，产品仍通过小程序源构建适配；部分布局已改造 | 逐页面对照本规范检查，不直接复制合成模板覆盖业务模板及权限处理 | 待分页面验收 |
| D-05 | 真实业务状态 / B-01～B-05 | 示例册只演示状态，不接真实任务、判断服务、AI 或权限 API | 在真实联调环境验证状态来源、超时恢复、任务完成回执与归档读回 | 待真实联调 |

顺序：新页面立即采用；已有高频页面优先处理 D-01／D-02；D-03 随页面整理；D-04／D-05 以对应本地和真实环境证据关闭。

这是“商汤销售小浣熊 Agent 中台”的联网安装包。

你要做的事：把完整压缩包和《安装说明.md》发给同事。

同事要做的事：
1. 准备一台 Ubuntu 22.04/24.04、Intel/AMD 64 位服务器。
2. 上传压缩包，按《安装说明.md》解压并运行两条安装命令。
3. 打开自己的网址，创建管理员，填写自己的模型 API Key。

建议服务器至少 4 核、8GB 内存、25GB 可用空间。
服务器需要能联网下载基础镜像。安装不是在 Mac 上运行。

安装出来的中台拥有同一套定制程序和界面，数据从空白开始。
不会带走原平台的账号、智能体、知识库、历史记录或任何模型密钥。
不依赖原服务器，也不会修改原平台。

默认启用自签名 HTTPS；正式部署可提供自己的域名和受信任证书。
具体命令、常见问题、CLI 授权方法，都在《安装说明.md》中。

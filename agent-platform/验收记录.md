# 安装包验收记录

版本：20260923；程序基线：定制 Dify 1.17.0。
分发形式：联网安装包，Linux amd64；独立新实例，不含生产业务数据和密钥。

## 已验证

- 在独立 Compose 项目、全新数据库和数据目录中启动；仅绑定测试机回环地址，未替换现有中台。
- 基础镜像按摘要锁定；使用已缓存镜像完成定制 API/Web 镜像构建，未依赖原平台运行容器的业务挂载。
- 17 个服务定义（16 个常驻服务、1 个完成后退出的权限初始化任务）通过状态检查。
- 初始化口令验证、新管理员创建、密码登录、Agent 列表初始为空、创建测试 Agent 成功。
- HTTPS API、登录页、品牌脚本及 favicon 可访问，证书验证开启。
- 初始 CLI 无授权时拒绝操作；显式授权后，通过真实网页登录会话确认设备授权、读取 Agent 列表成功；跨空间请求被拒绝，退出后撤销 Token。
- 为新管理员开通创建工作空间权限成功。
- 使用新生成的内部 Key 调用沙箱执行 `print(2 + 3)`，返回 5。
- 共享密钥配对、新实例密钥随机生成、空身份白名单、无效 URL 拒绝和未配置 CLI 拒绝执行等检查通过。
- 发布包不含生产 .env、证书私钥、数据库、上传文件、个人 CLI 会话、管理员 SSH 入口和 .private 目录；源实例 IP 与账号/空间绑定已移除。
- 包内逐文件 SHA256 清单及外层压缩包 SHA256 校验。

首次启动测试发现空目录覆盖了沙箱镜像自带配置，最终 Compose 已去掉该覆盖；沙箱重建和带鉴权代码执行均通过。

## 验证边界

- 验收机器已安装 Docker；未重新安装操作系统，也未重新下载全部已有基础镜像。
- 未携带或调用生产模型 Key，没有消耗模型额度。真实模型回答、供应商专用插件、邮件、外部 MCP 和业务系统，需要安装者配置后各自验收。
- 已检查服务与 HTTP 接口，不代表逐个网页组件的完整视觉/交互回归，也不是并发压测。
- 这是当前程序版本的分发包，不是生产数据库克隆、自动升级包或离线镜像全集。
